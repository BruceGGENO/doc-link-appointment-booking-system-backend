# DocLink Appointment Booking System

## Full Names: Geno Bruce
## ID: 27193

DocLink Appointment System is a project I worked on using Java, Spring Boot and PostgreSQL.It allows members to book medical appointments with doctors based on their specializations or medical fields. It can manage the members, doctors/practitioners, rooms and notes 

### How to run It
1. Clone the repository and open the `demo` folder:
   git clone https://github.com/BruceGGENO/doc-link-appointment-booking-system-backend
   cd doc-link-appointment-booking-system-backend/demo
2. Create an empty database named `doclink`.
3. Check `src/main/resources/application.properties` and change the user and password according to the ones you set in your database.
4. Start the API: run the command 'mvn spring-boot:run'
